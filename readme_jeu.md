# Documentation du Jeu - Hakimi & PSG Quest

## Vue d'ensemble

Hakimi & PSG Quest est un jeu de géolocalisation où vous devez explorer Paris pour collecter des objets et résoudre des énigmes. Le jeu propose **3 scénarios** différents, chacun avec **5 objets** à trouver dans un ordre spécifique.

---

## Scénario 1 : Hakimi Quest (Ouest Paris)

**Objectif** : Trouver la clé d'or d'Hakimi 

### Ordre de collecte des objets :

#### 1. Chaussure de Vitesse
- **Type** : Objet récupérable
- **Emplacement** : Tour Eiffel
- **Indice** : Disponible dès le départ
- **Icône** : `speed_boots.png`
- **Action** : Débloque le Casque Audio de Concentration

#### 2. Casque Audio de Concentration
- **Type** : Objet bloqué (nécessite la Chaussure de Vitesse)
- **Emplacement** : Arc de Triomphe
- **Indice** : "Tu n'iras pas loin si tu n'entends pas les supporters"
- **Icône** : `headset.png`
- **Action** : Débloqué après avoir récupéré la Chaussure de Vitesse

#### 3. Téléphone Cryptex
- **Type** : Objet code (donne un code)
- **Emplacement** : Trocadéro
- **Indice** : Disponible dès le départ
- **Icône** : `phone.png`
- **Code donné** : **1970**
- **Action** : Le code 1970 est nécessaire pour débloquer la Carte d'Entraînement

#### 4. Carte d'Entraînement
- **Type** : Objet bloqué par code (nécessite le code 1970)
- **Emplacement** : Parc des Princes
- **Indice** : "Cherche là où résonnent les chants"
- **Icône** : `training_card.png`
- **Code requis** : **1970** (donné par le Téléphone Cryptex)
- **Action** : Débloque le Sésame d'Hakimi

#### 5. Le Sésame d'Hakimi (Objet Final)
- **Type** : Objet final
- **Emplacement** : Pont Mirabeau
- **Indice** : Débloqué après avoir récupéré la Carte d'Entraînement
- **Icône** : `golden_key.png`
- **Action** : Termine le scénario Hakimi Quest

### Explication du scénario

**Objectif** : Collecter le **Sésame d'Hakimi** pour terminer le scénario. Le parcours traverse l'Ouest de Paris, en référence au style de jeu d'Hakimi (vitesse, passes décisives).

**Parcours géographique** : Tour Eiffel → Arc de Triomphe → Trocadéro → Parc des Princes → Pont Mirabeau

### Points communs

- Tous les scénarios ont **5 objets** à collecter
- Chaque scénario a un **code secret** lié au joueur
- Les scénarios se terminent par un **objet final emblématique**
- Le parcours couvre différentes zones de Paris
- Les indices font référence aux lieux emblématiques parisiens

---

## Mécaniques de jeu

### Types d'objets

1. **Récupérable** : Objet disponible dès le départ ou après déblocage, peut être collecté directement
2. **Code** : Objet qui révèle un code à 4 chiffres nécessaire pour débloquer un autre objet
3. **Bloqué par objet** : Nécessite de posséder un autre objet spécifique avant d'être accessible
4. **Bloqué par code** : Nécessite d'entrer le bon code pour être débloqué
5. **Final** : Dernier objet du scénario, termine la partie

### Système de points

- **Objet normal** : 5 points
- **Objet final** : 50 points (20 points si le mode triche a été utilisé)
- **Avec mode triche** : 1 point par objet

### Mode triche (Heatmap)

Le mode triche affiche une heatmap sur la carte indiquant la position approximative de l'objet recherché. L'utilisation de ce mode réduit les points gagnés.

---

## Notes importantes

- Les objets doivent être collectés dans l'ordre indiqué
- Certains objets nécessitent un niveau de zoom minimum pour être visibles sur la carte
- Les codes sont stockés dans l'inventaire une fois récupérés
- Le score est cumulatif entre les différentes parties
- Chaque scénario peut être joué indépendamment
